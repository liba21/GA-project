# Genetic Algorithm for Epistasis Detection

## Project Overview

This project investigates the detection and estimation of genetic epistatic interactions using a Genetic Algorithm (GA), and compares its performance with statistical approaches.

The project uses a simulated genetic population in which:

- Each individual is represented by genotypes at multiple genetic loci.
- Each locus has a main genetic effect (β).
- A subset of pairs of loci has an epistatic interaction effect (γ).
- A binary disease phenotype is generated according to a logistic model.
- GWAS is performed to estimate the main effects of individual loci.
- The estimated GWAS effects are used to construct a Polygenic Risk Score (PRS).
- Several approaches are then used to detect and estimate epistatic interactions:
  1. Grid Search
  2. Logistic Regression-based scanning
  3. Genetic Algorithm

The main goal is to investigate whether a Genetic Algorithm can recover true epistatic interactions more effectively than approaches that evaluate each pair independently.

## Methodology

The complete analysis is divided into several stages. The scripts should generally be executed in the order described below because later stages depend on files generated by earlier stages.

---

## 1. Data Generation

### <span style="color:red"><code>modular_create_population.py</code></span>

The first stage of the project is the generation of a simulated genetic population.

The script generates:

- Main genetic effects (β) for each locus.
- Minor allele frequencies (MAF).
- Epistatic pairs of loci.
- Genotypes for all individuals.
- Main PRS.
- Epistatic effects.
- Total genetic risk score.
- Disease probability.
- Binary disease phenotype.

The simulated phenotype is generated using a logistic model.

### Main parameters

The simulation uses parameters such as:

- `n_loci = 100`  
  Number of genetic loci.
- `N = 100000`  
  Number of simulated individuals.
- `target_prev = 0.02`  
  Target disease prevalence.
- `epi_fraction_pairs = 0.1`  
  Fraction of all possible locus pairs that are epistatic.

For 100 loci, the number of possible pairs is:

```text
100 choose 2 = 4950
```

Therefore, when `epi_fraction_pairs = 0.1`, approximately:

```text
495 epistatic pairs
```

are generated.

- `sigma = 0.15`  
  Standard deviation used when generating the epistatic interaction coefficients.
- `epi_variance_fraction = 0.3`  
  Target contribution of epistatic effects to the genetic variance.

### Output

The script creates the main input files used by the rest of the project:

```text
data/population.csv
data/real_betas.csv
data/real_epistasis.csv
```

### Population data

<span style="color:red"><code>population.csv</code></span> contains:

- `Locus_0`, `Locus_1`, ..., `Locus_99`
- `PRS_total`
- `logit`
- `P(D)`
- `label`

The `label` column represents the phenotype:

```text
0 = healthy
1 = disease
```

### True main effects

<span style="color:red"><code>real_betas.csv</code></span> contains the true β value for each locus.

### True epistatic effects

<span style="color:red"><code>real_epistasis.csv</code></span> contains all possible locus pairs and their corresponding γ values.

A γ value of zero means that the pair is not truly epistatic.

## 2. GWAS Analysis

### <span style="color:red"><code>gwas_analysis.py</code></span>

The second stage performs a GWAS analysis on the simulated population.

The purpose of this stage is to estimate the main genetic effect of each individual locus without explicitly modeling epistasis.

For every locus, a separate logistic regression is fitted:

```text
log(P(Y=1) / P(Y=0)) = α + βx
```

where:

- `Y` is the disease phenotype.
- `x` is the genotype dosage of the locus (0, 1, or 2).
- `β` is the estimated effect of the locus.

For each locus, the analysis records:

- Estimated effect size `beta_hat`
- Odds ratio `OR`
- p-value

The p-values are corrected using the Bonferroni correction to account for multiple testing.

### Output

The main GWAS result is:

```text
results/GWAS/gwas_results.csv
```

The results include:

```text
locus
beta_hat
OR
p_value
p_adj
```

The GWAS analysis is also used to compare:

- True β values from the simulation
- β values estimated by GWAS

This provides an initial evaluation of how well the GWAS can recover the simulated main effects.

---

## 3. ROC Analysis and PRS Evaluation

### <span style="color:red"><code>roc_curves.py</code></span>

Before attempting to detect epistasis, the project evaluates how well the GWAS results alone can predict disease.

First, significant loci from the GWAS are selected according to the adjusted p-value threshold.

Their estimated β values are then combined to construct a GWAS-based Polygenic Risk Score:

```text
PRS_GWAS = Σ β_hat_i × genotype_i
```

The predictive performance of this score is evaluated using an ROC curve and the Area Under the Curve (AUC).

The analysis first evaluates:

```text
GWAS PRS only
```

and then evaluates the effect of gradually adding knowledge about the strongest epistatic interactions.

The tested knowledge levels are:

```text
0%
10%
25%
50%
75%
100%
```

where the percentage represents the fraction of the strongest true epistatic interactions that are assumed to be known.

This provides a baseline for understanding how much predictive performance can be gained from epistatic information.

### Outputs

ROC and AUC-related figures are saved under:

```text
figures/GWAS/
```

The results are used as a baseline for the later epistasis-detection methods.

---

## 4. Statistical Epistasis Detection

After establishing the GWAS baseline, two approaches are used to investigate whether epistatic interactions can be detected statistically.

These methods evaluate locus pairs independently rather than optimizing a complete set of interacting pairs simultaneously.

---

## 4.1 Grid Search

### <span style="color:red"><code>grid_search_scan.py</code></span>

The Grid Search approach evaluates possible γ values for locus pairs.

For each tested pair:

1. A set of possible γ values is defined.
2. The effect of the pair is added to the GWAS-based PRS.
3. The resulting predictive performance is evaluated using AUC.
4. The γ value producing the highest AUC is selected as the estimated interaction effect for that pair.

The analysis can be performed for:

- All possible pairs.
- A selected subset such as the top 125 pairs.

The resulting estimates are compared with the true γ values from the simulation.

### Outputs

The Grid Search results are stored under:

```text
results/Grid_Search/
```

These results allow comparison between:

```text
true γ
```

and:

```text
predicted γ
```

as well as evaluation of how many true epistatic pairs are recovered.

---

## 4.2 Logistic Regression-based Epistasis Scan

### <span style="color:red"><code>logistic_epistasis_scan.py</code></span>

The second statistical approach attempts to estimate epistatic effects using a logistic regression-based method.

For each candidate pair, the interaction between the two loci is considered as an additional predictor of disease risk.

The estimated interaction coefficient is then compared with the true γ value used during simulation.

As with the Grid Search approach, the method evaluates pairs individually rather than optimizing the entire collection of pairs simultaneously.

The results are used to determine:

- How accurately γ values can be estimated.
- How many true epistatic pairs can be detected.
- Whether the statistical approach can distinguish strong interactions from non-interacting pairs.

### Outputs

The results are stored under:

```text
results/Logistic/
```

---

## 5. Genetic Algorithm

### <span style="color:red"><code>genetic_algorithm_epistasis.py</code></span>

The main method of the project is a Genetic Algorithm designed to identify a collection of important epistatic interactions simultaneously.

Unlike the statistical approaches, which evaluate each pair independently, the Genetic Algorithm searches for a complete solution containing multiple interacting pairs.

The goal is to find a set of pairs and γ values that maximizes disease-prediction performance.

---

## 5.1 Candidate pairs

For 100 loci there are:

```text
4950
```

possible pairs.

The Genetic Algorithm searches among these candidate pairs.

The solution is constrained to contain:

```text
125 pairs
```

This means that the algorithm must select a relatively small subset of the 4950 possible interactions.

---

## 5.2 Individual representation

Each Genetic Algorithm individual consists of 125:

```text
(pair, gamma)
```

elements.

For example:

```text
((3, 27), 0.14)
((10, 42), -0.21)
((5, 91), 0.08)
...
```

Each individual therefore represents a possible explanation of the phenotype using 125 epistatic interactions.

---

## 5.3 Fitness Function

The fitness of an individual is based on the predictive performance of the resulting PRS.

The algorithm starts with the GWAS-based main-effect PRS:

```text
PRS_main
```

and adds the epistatic contribution represented by the individual.

The resulting score is evaluated using ROC AUC.

Therefore:

```text
Fitness = AUC
```

A higher AUC means a better solution.

The Genetic Algorithm therefore searches for a combination of pairs and γ values that maximizes AUC.

---

## 5.4 Initial Population

The initial population consists of randomly generated candidate solutions.

Each solution:

- Selects 125 random locus pairs.
- Assigns an initial γ value to each pair.

The population size is:

```text
POP_SIZE = 2000
```

---

## 5.5 Selection

The algorithm uses rank-based selection.

Individuals are ranked according to their fitness.

Higher-fitness individuals receive a higher probability of being selected as parents.

This allows good solutions to contribute more strongly to the next generation while still maintaining some diversity in the population.

---

## 5.6 Crossover

Two parent solutions are combined using crossover.

A random cut point is selected, and part of one parent is combined with part of the other.

Because the solution must contain unique pairs, duplicate pairs are removed and replaced with new candidate pairs.

The solution therefore remains fixed at:

```text
125 unique pairs
```

---

## 5.7 Mutation

Mutation introduces new genetic variation into the population.

Two types of mutation are possible:

### Pair mutation

One selected pair is replaced with another random candidate pair.

### γ mutation

The γ value associated with one pair is modified by adding a small random perturbation.

The γ value is then constrained to the allowed range:

```text
-0.4 ≤ γ ≤ 0.4
```

---

## 5.8 Elitism

The best individuals from each generation are copied directly to the next generation.

The number of elite individuals is:

```text
ELITE_SIZE = 5
```

This ensures that the best solutions found so far are not lost during reproduction.

---

## 5.9 Early Stopping

The algorithm monitors both:

```text
Best AUC
Mean AUC
```

If both values remain stable for a predefined number of consecutive generations, the algorithm stops early.

This prevents unnecessary computation once the population has converged.

---

## 5.10 Recovery Metrics

The algorithm is evaluated using two main recovery metrics.

### Recall@125

Recall measures how many of the true epistatic pairs were recovered among the selected 125 pairs.

For example, if 64 true pairs are found:

```text
Recall@125 = 64 / 495
```

This measures the ability of the algorithm to identify true interactions.

### Mean Gamma Error

For recovered true pairs, the absolute difference between the predicted and true γ values is calculated:

```text
|γ_predicted - γ_true|
```

The mean of these errors is reported as the Mean Gamma Error.

A smaller value indicates more accurate estimation of the interaction strength.

---

## 5.11 GA Parameters

The main Genetic Algorithm parameters are:

```text
Population size:       2000
Maximum generations:   600
Solution size:         125 pairs
Selection:             rank-based selection
Elite size:            5
Pair mutation probability: 0.5
Gamma mutation probability: 0.5
Gamma range:           [-0.4, 0.4]
```

The algorithm can be run multiple times because the initial population and mutation processes are stochastic.

## 7. GA AUC Convergence Plot

The plot shows:

- Best AUC in each generation.
- Average AUC of the population in each generation.

The purpose of this plot is to determine whether the Genetic Algorithm is learning and converging.

A typical successful run should show an increase in the best AUC during the early generations, followed by stabilization as the algorithm converges.


## 8. True vs Predicted Epistatic Effects

### <span style="color:red"><code>final_found_pairs_graph.py</code></span>

The selected true epistatic pairs are compared according to:

```text

```

The closer the predicted values are to the true values, the better the estimation.

The script also reports metrics such as:

- Number of recovered true pairs.
- Mean γ estimation error.

This provides a direct visualization of how well the Genetic Algorithm learned the magnitude and direction of the true epistatic effects.

The resulting figure is saved under:


Multiple runs provide stronger evidence that the observed performance is not the result of a single favorable random initialization.

## 12. Main Comparison

The central comparison in the project is between methods that evaluate interactions individually and a Genetic Algorithm that optimizes multiple interactions simultaneously.

### Statistical approaches

The Grid Search and Logistic Regression approaches evaluate individual pairs independently.

For each pair, they attempt to find the γ value that provides the best statistical or predictive result.

This approach does not explicitly optimize the interactions jointly as a complete model.

### Genetic Algorithm

The Genetic Algorithm evaluates complete sets of 125 interactions.

Its fitness is determined by the AUC of the combined model:

```text
GWAS main effects + epistatic effects
```

The algorithm therefore searches for interactions that work well together as part of the complete genetic risk model.

The main evaluation criteria are:

```text
AUC
Recall@125
Mean Gamma Error
```

A successful result is characterized by:

- Increasing AUC during the GA run.
- Recovery of a substantial number of true epistatic pairs.
- Predicted γ values that follow the trend of the true γ values.
- Lower γ estimation error.
- Consistent performance across multiple independent runs.

---

## 13. Interpretation of the Main Results

The project is designed to demonstrate that epistasis detection is difficult when interactions are evaluated individually.

There are 4950 possible pairs, while only 495 are truly epistatic in the simulated population.

The Genetic Algorithm searches for only 125 pairs out of these 4950 candidates.

Therefore, random selection would be expected to recover only a small fraction of the true interactions.

If the GA consistently recovers substantially more true pairs than random selection, this indicates that the algorithm has learned meaningful information about the underlying genetic architecture.

The comparison of true and predicted γ values provides an additional measure of learning.

A strong correspondence between the two indicates that the algorithm is not merely identifying relevant pairs, but is also learning the approximate direction and magnitude of their effects.

## 14. Reproducibility

The project contains stochastic components, including:

- Random generation of β values.
- Random selection of epistatic pairs.
- Random genotype generation.
- Random initialization of the Genetic Algorithm.
- Mutation and crossover.

Therefore, different executions may produce somewhat different results.

For robust evaluation, the Genetic Algorithm should be executed multiple times and the results should be analyzed collectively.

The current analysis uses six independent GA runs.

## 17. Summary

The project follows a complete computational genetics workflow:

1. Simulate a genetic population with main effects and epistatic interactions.
2. Perform GWAS to estimate individual-locus effects.
3. Construct and evaluate a GWAS-based PRS.
4. Test statistical approaches for detecting epistasis.
5. Apply a Genetic Algorithm to jointly search for important epistatic interactions.
6. Evaluate the recovered interactions using Recall@125 and Mean Gamma Error.
7. Visualize GA convergence and the relationship between true and predicted γ values.
8. Repeat the GA multiple times and analyze the consistency of the results.

The overall objective is to determine whether a Genetic Algorithm can recover meaningful epistatic interactions from a large search space and whether it provides an advantage over simpler pair-wise statistical approaches.
